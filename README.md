# Block Pilot — 打飞机 × 俄罗斯方块

最小可玩网页原型（MVP v1）：带降落伞的方块从上方下落，你在底部开飞机射击。打掉伞会加速下落；打中下落块的格子足够次数会削掉该格；落地后完整横行消除得分。撞块扣血，血空 Game Over。

## 玩法

1. 盘面 **10×20**，方块在 4×4 包围盒内随机连通形状生成，水平位置随机，带伞慢落。
2. **射击打伞**（伞宽 3 格，居中对齐块；打中任一格即破）→ 该块加速下落。
3. **射击下落块格子**（默认 2 击）→ 该格消失（整形）。已落地堆叠不可打穿。
4. 块锁定后 **消行计分**。
5. 飞机可在盘面四向飞行，不出界、不穿已落堆叠；碰到下落块或已落方块扣血；生命归零 Game Over。
6. 第一版不做炸弹 / 隐身。

## 操作

| 平台 | 移动 | 射击 | 暂停 |
|------|------|------|------|
| 桌面 | WASD / 方向键（上下左右） | 空格 / J | P / Esc |
| 手机 | ▲▼◀▶ 触控 | 🔥 | ⏸ |

Game Over 后按 **R** 或点「再来一局」。

## 本地启动

需要 Node.js ≥ 20（推荐 22）与 pnpm。

```bash
pnpm install
pnpm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

```bash
pnpm test      # 核心逻辑单测
pnpm run build # 产出 dist/
pnpm run preview
```

## 技术栈

- Vite + TypeScript + Canvas 2D
- Vitest（形状生成、消行、击中消格、伞破加速）

## 已知限制

- 已落地堆叠不可射击打穿。
- 无炸弹、无隐身、无连击特效。
- 下落块不支持玩家手动旋转。
- 单块同时仅一个下落；无幽灵预览。
- 触控为方向键 + 射击/暂停，非全屏虚拟摇杆。
- 音效 / 排行榜未做。
